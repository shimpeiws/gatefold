# Gatefold 1.0.0

First stable release. The public surface — commands, result schemas,
exit codes, package exports — is frozen under the
[1.0 contract](../1.0-contract.md) and follows the SemVer policy defined
there.

## Stable surface

| Command | Result schema | Status |
| --- | --- | --- |
| `gatefold <input.json>` / `gatefold -` | `claim-result.v2.json` | stable |
| `gatefold compare --before --after --diff` | `claim-result.v3.json` | stable |
| `gatefold compare-traces --before --after` | `claim-result.v4.json` | stable |
| `gatefold compare-runs --before --after` | `claim-result.v5.json` | stable |
| `gatefold audit-run --run [--check-report]...` | `claim-result.v8.json` | stable |
| `gatefold report-cell --run [--evaluation]` | `claim-result.v9.json` | stable |
| `gatefold compare-cells --before --after [--evaluation]` | `claim-result.v9.json` | stable |
| `gatefold report-cells --run ×2–32` | `claim-result.v10.json` | stable |

Schema v1 remains readable; readers keep every documented version
working.

Package exports: `.` is frozen at the names listed in the contract's
"Package and module surface" section; `./schema/*` publishes every
committed schema; `./internal` holds helpers outside the SemVer promise.

## Deprecated

`evaluate-run` and `compare-evaluations` (schemas v6/v7) are deprecated:
frozen, retained through the whole 1.x line, removal is a 2.0 decision.
Verdict ownership moves to the analyze layer — see the
[migration mapping](../v0.7-scope.md#migration-mapping-to-the-analyze-model)
(recorded under issue #88).

## Known limitations

- Gatefold reports what records show, never which side is better or what
  caused a difference; verdicts belong to the analyze layer.
- `statement`/`reason` prose is not a stable API — consumers branch on
  `schemaVersion`, ids, states, and fields (see the
  [analyze accessor contract](../analyze-accessor-contract.md)).
- Human-format output escapes control characters for terminal safety;
  JSON output preserves source values verbatim.
- Inputs are bounded: 16 MiB per file/stdin read, path confinement for
  run-directory artifacts, documented output ceilings.
